Installation & Setup

Installing on Windows 10 / 11

RUHI Browser is distributed as a verified app on the Microsoft Store. Simply click "GET IT FROM Microsoft Store" on our home page or open the Microsoft Store app in Windows and search for RUHI Browser. Updates install automatically via Windows Store services.

Installing on Apple Mac (macOS)

Download the universal RuhiBrowser_macOS.dmg disk image from our website. Double-click to mount the DMG, drag the RUHI Browser app into your Applications folder, and launch it directly. Compatible with Apple Silicon (M1–M4) and Intel Macs.

Installing on Android Devices

RUHI Browser for Android is available on the Google Play Store. Search RUHI Browser on Google Play or tap our badge link. Minimum requirement is Android 6.0 (Marshmallow) or higher. Supports phones, tablets, and foldable devices.

Setting as Default Browser

Windows: Windows Settings → Apps → Default apps → search RUHI Browser → "Set default".
macOS: System Settings → Desktop & Dock → Default web browser → select RUHI Browser.
Android: Settings → Apps → Default apps → Browser app → select RUHI Browser.

Browsing & Tab Management

Smart Tabstrip Management

Open new tabs by clicking the + button on the title bar or pressing Ctrl + T. Close any tab with Ctrl + W. Reopen accidentally closed tabs instantly with Ctrl + Shift + T.

AMOLED Dark Mode (Android)

Engineered with true #000000 pitch-black charcoal styling to preserve maximum battery life on modern OLED & AMOLED displays. Activates automatically based on your system theme or via Browser Settings.

Built-in PDF Reader & Printing

Open, view, search, and print PDF documents directly inside RUHI Browser without needing external bloated software. Press Ctrl + P to print any web article or save it as a clean PDF.

Bookmarks & Favorites

Save your favorite websites with a single click on the bookmark star or press Ctrl + D. You can organize bookmarks into custom folders and import HTML bookmarks from other browsers in Settings.

Privacy, Security & AdBlock

Intelligent AdBlock

RUHI Browser features native network-level filtering. It automatically blocks pop-ups, intrusive video pre-rolls, banner advertisements, and third-party tracking beacons before they download, saving mobile data and boosting speed.

Incognito / Private Browsing

Launch an isolated Private Session with Ctrl + Shift + N. In private mode, no browsing history, search records, or persistent cookies are saved to disk once you close the window.

Hardware DPAPI Encryption

Your saved passwords and credentials on Windows are encrypted with Windows DPAPI (Data Protection API). Keys are tied to your Windows user account and hardware TPM, preventing credential extraction by malicious software.

Clearing Cache & History

To purge temporary files, cookies, or cache, press Ctrl + Shift + Delete or open Settings → Privacy → Clear Browsing Data. Choose your time range and click Clear.

Troubleshooting & FAQs

Webpages Not Loading or Broken

1. Check your internet connection.
2. Perform a hard refresh using Ctrl + F5.
3. Disable AdBlock temporarily for the specific domain if the website enforces an aggressive anti-adblock script.
4. Clear your browser cache via Ctrl + Shift + Del.

Microsoft Store Installation Issues

If Microsoft Store fails to download, reset the Windows Store cache: press Win + R, type wsreset.exe, and press Enter. Once complete, relaunch the Store and install RUHI Browser.

Video Playback or Streaming Stutter

RUHI Browser uses hardware-accelerated Chromium rendering. Ensure your graphics card driver is up to date (Intel, AMD, or NVIDIA). In Windows Settings → System → Display → Graphics, set RUHI Browser to "High performance".

Android Crashing or Slowing Down

Open Android Settings → Apps → RUHI Browser → Storage → tap "Clear Cache". Make sure your device has at least 150 MB of free storage for smooth browser operation.
