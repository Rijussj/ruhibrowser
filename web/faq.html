Frequently Asked Questions

Everything you need to know about RUHI Browser across Windows and Android platforms.

General Questions

Is RUHI Browser completely free to use? +
Yes! RUHI Browser is 100% free with no in-app purchases, paid subscriptions, or paywalled features. All privacy, ad-blocking, and performance tools are fully unlocked for all users on both Windows and Android.
Who develops and publishes RUHI Browser? +
RUHI Browser is developed by independent software engineer Saikh Sufian and published officially under RUHI Applications.
What rendering engine powers RUHI Browser? +
RUHI Browser is engineered on the industry-standard Chromium rendering core. On Windows, it leverages Microsoft WebView2 runtime with hardware GPU acceleration. On Android, it utilizes high-efficiency Chromium/WebKit mobile rendering.
How do I receive the latest browser updates? +
Because RUHI Browser is distributed via official app stores (Microsoft Store on Windows and Google Play Store on Android), new updates and security patches install automatically in the background without needing manual file downloads.

Windows Desktop Experience

Which versions of Windows are supported? +
RUHI Browser supports 64-bit (x64) editions of Windows 11 and Windows 10 (Build 1809 or later).
How do I install RUHI Browser on Windows? +
Simply click the GET IT FROM Microsoft Store button on our website or open the Windows Microsoft Store app, search for RUHI Browser, and click "Get". Windows handles installation and setup seamlessly.
Does RUHI Browser support built-in PDF viewing and printing? +
Yes. RUHI Browser includes an integrated, lightweight PDF viewer. You can open any PDF document, search inside the document, zoom, and print directly by pressing Ctrl + P.
Can I import my bookmarks from Chrome, Edge, or Firefox? +
Yes. Open Settings → Bookmarks → Import Bookmarks, choose your exported HTML bookmarks file from any other web browser, and your bookmarks will be imported instantly.

Android Mobile App

What are the system requirements for Android? +
RUHI Browser for Android requires Android 6.0 (Marshmallow) or higher. The app package is ultra-lightweight (under 6 MB) and runs smoothly on both entry-level and flagship devices.
How does the AMOLED Pure Black Mode work? +
Unlike standard dark modes that use dark gray tones, RUHI Mobile features true pitch-black (hex #000000) styling. On OLED and AMOLED screens, black pixels are completely turned off, drastically saving battery life during browsing sessions.
Does RUHI Mobile run background tracking services? +
No. RUHI Mobile does not start any background telemetry daemons, persistent notification push services, or analytics loggers. When you close the app, it stops consuming CPU and memory immediately.

Privacy & Security

Does RUHI Browser collect, track, or sell my personal browsing data? +
Strictly NO. RUHI Browser was designed from inception with a Zero-Telemetry architecture. We do NOT log, collect, transmit, or monetize your URLs, search queries, browsing history, or IP address. Everything stays stored strictly on your local device.
How are my saved passwords and credentials protected? +
On Windows, your saved credentials are encrypted using Windows DPAPI (Data Protection API) tied cryptographically to your Windows user account and hardware profile. On Android, data is protected by native OS sandboxing and keystore encryption.
What happens in Private / Incognito Mode? +
In Private Mode (open with Ctrl + Shift + N), RUHI Browser runs in a separate, memory-only session. Once you close the private window, all history, session cookies, and temporary site data from that session are wiped completely.
How can I clear my browsing history and cache? +
Press Ctrl + Shift + Delete on Windows or open Settings → Privacy → Clear Data on Android. You can choose to purge cached images, cookies, or history for any timeframe.

AdBlock & Performance

How does the built-in intelligent AdBlock work? +
RUHI Browser features native network-level filtering rules that prevent banner advertisements, intrusive pop-ups, pre-roll video ads, and cross-site tracking scripts from ever downloading. This results in up to 3x faster webpage loads and significantly lower bandwidth usage.
Can I disable AdBlock for a specific website? +
Yes. Click the shield icon in the browser toolbar and toggle the AdBlock switch to "Off" for that specific domain if the website requires ads to view its content.
Why is RUHI Browser faster and lighter than traditional browsers? +
Most commercial browsers bundle gigabytes of telemetry reporters, AI data-harvesting tools, news feeds, and sponsored extensions. RUHI Browser strips away all that bloat, keeping only essential Chromium browsing rendering, local hardware acceleration, and AdBlock.
