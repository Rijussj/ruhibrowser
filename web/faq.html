Frequently Asked Questions

Everything you need to know about RUHI Browser across Windows, Android, and macOS platforms.

General Questions

Is RUHI Browser completely free to use? +
Yes! RUHI Browser is 100% free with no in-app purchases, paid subscriptions, or paywalled features. All privacy, ad-blocking, and performance tools are fully unlocked across Windows, Android, and macOS.
Who develops and publishes RUHI Browser? +
RUHI Browser is developed by independent software engineer Saikh Sufian and published officially under RUHI Applications.
What rendering engine powers RUHI Browser on each platform? +
RUHI Browser uses the optimal native engine for each operating system:
  • Windows: Powered by Microsoft WebView2 (Chromium Evergreen) with hardware GPU acceleration.
  • Android: Powered by high-efficiency Android System WebView and Kotlin Jetpack architecture.
  • macOS: 100% Native Apple WebKit and Swift 5.10 Cocoa architecture (zero Electron bloat).
How do I receive the latest browser updates? +
Updates are provided through official platform channels:
  • Windows: Automatically updated via Microsoft Store, or direct installer download.
  • Android: Automatically updated via Google Play Store, or direct APK download.
  • macOS: Downloadable as universal `.dmg` release packages directly from our website and GitHub.
Can I sync my bookmarks and active tabs across my devices? +
Yes! RUHI Browser features integrated Supabase Cloud Sync, allowing you to seamlessly share active tabs and sync bookmarks between your Windows PC, Android smartphone, and Apple Mac.

Windows Desktop Experience

Which versions of Windows are supported? +
RUHI Browser supports 64-bit (x64) editions of Windows 11 and Windows 10 (Build 1809 or later).
How do I install RUHI Browser on Windows? +
You can download the standalone installer (RuhiBrowserSetup.exe) directly from our website, or install it from the Microsoft Store with automatic background updates.
Does RUHI Browser support built-in PDF editing and annotation? +
Yes! Unlike basic viewers, RUHI Browser includes an integrated PDF editor with a freehand ink pen, highlighter, eraser, and text annotation tools. You can view, mark up, and save changes to PDF files offline without third-party software.
What is the Dual-View Split Screen feature? +
Split Screen lets you display two tabs side-by-side inside a single browser window. This is ideal for comparing documents, watching a lecture while taking notes, or researching without juggling multiple windows.
Can I import my bookmarks from Chrome, Edge, or Firefox? +
Yes. Open Settings → Bookmarks → Import Bookmarks, choose your exported HTML bookmarks file from any other web browser, and your bookmarks will import instantly.

Android Mobile App

What are the system requirements for Android? +
RUHI Browser for Android requires Android 6.0 (Marshmallow) or higher (up to Android 15+). The package is featherlight (only ~5.4 MB) and runs silky-smooth on both budget and flagship devices.
How does the AMOLED Pure Black Mode work? +
Unlike standard dark modes that use washed-out dark gray tones, RUHI Mobile features true pitch-black (hex #000000) charcoal styling. On OLED and AMOLED screens, black pixels turn completely off, saving up to 40% battery life during reading sessions.
What is the One-Handed Bottom Omnibox? +
Modern smartphone screens are tall and hard to navigate with one hand. RUHI Mobile positions the address bar and essential navigation buttons at the bottom of the screen, within comfortable reach of your thumb.
Does RUHI Mobile run background tracking services? +
Strictly NO. RUHI Mobile does not start any background telemetry daemons, persistent notification push services, or analytics loggers. When you close the app, it stops consuming CPU and memory immediately.
How do I install RUHI Browser on Android? +
You can download RUHI Browser from the Google Play Store, or download the direct APK (RuhiBrowser_Android.apk, ~5.4 MB) straight from our website for instant sideloading.

macOS Native Experience

Which macOS versions and Mac computers are supported? +
RUHI Browser for Mac supports macOS 12 (Monterey), macOS 13 (Ventura), macOS 14 (Sonoma), and macOS 15 (Sequoia). It is compiled as a Universal Binary with native support for Apple Silicon (M1, M2, M3, M4) and Intel Macs.
How do I install RUHI Browser on a Mac? +
Download the RuhiBrowser_macOS.dmg disk image from our website. Double-click the DMG file to mount it, drag the RUHI Browser icon into your Applications folder, and launch it from Launchpad or Spotlight.
Is RUHI Browser for Mac built with Electron? +
No! RUHI Browser for Mac is 100% Apple Native, crafted in Swift 5.10 and SwiftUI using the Apple WebKit Cocoa engine. It contains zero Electron overhead, starts in milliseconds, uses minimal RAM, and runs whisper-quiet without triggering MacBook fan noise.
How does AdBlock work on macOS? +
RUHI for Mac utilizes Apple WebKit's native ContentRuleList API. Ad-blocking rules are compiled directly into the WebKit rendering pipeline, blocking ads, trackers, and popup redirects natively with zero JavaScript CPU overhead.
How are passwords protected on macOS? +
Passwords and sensitive credentials are encrypted locally using the hardware-backed Apple Keychain Services (Secure Enclave). Credentials can be unlocked with your Mac password or biometric Touch ID.
What keyboard shortcuts are supported on macOS? +
RUHI for Mac supports standard macOS conventions:
  • Cmd + T: Open New Tab
  • Cmd + Shift + N: Open New Private Window
  • Cmd + W: Close Active Tab
  • Cmd + J: Open Downloads Folder in Finder
  • Cmd + ,: Open Browser Settings
  • Cmd + R: Reload Page

Privacy & Security

Does RUHI Browser collect, track, or sell my personal browsing data? +
Strictly NO. RUHI Browser was designed from inception with a Zero-Telemetry architecture. We do NOT log, collect, transmit, or monetize your URLs, search queries, browsing history, or IP address. Everything stays stored strictly on your local device.
How are my saved passwords and credentials protected? +
Passwords are encrypted locally using the strongest hardware security on each operating system:
  • Windows: Encrypted using Windows DPAPI (Data Protection API) tied to your local user master key.
  • Android: Encrypted with hardware-backed Android Keystore and EncryptedSharedPreferences.
  • macOS: Encrypted inside Apple Keychain with Secure Enclave hardware and Touch ID protection.
What happens in Private / Incognito Mode? +
In Private Mode, RUHI Browser runs in a separate, memory-only session. Once you close the private window, all history, session cookies, and temporary site data from that session are wiped completely from RAM.
Is WireGuard VPN integrated into RUHI Browser? +
Yes! RUHI Browser features built-in WireGuard protocol management, allowing you to establish high-speed encrypted tunnels to safeguard your web connection on unsecured public Wi-Fi networks.
How can I clear my browsing history and cache? +
Press Ctrl + Shift + Delete on Windows, Cmd + Shift + Delete on Mac, or open Settings → Privacy → Clear Data on Android. You can choose to purge cached images, cookies, or history for any timeframe.

AdBlock & Performance

How does the built-in intelligent AdBlock work? +
RUHI Browser features native network-level filtering rules that prevent banner advertisements, intrusive pop-ups, pre-roll video ads, and cross-site tracking scripts from ever downloading. This results in up to 3x faster webpage loads and significantly lower bandwidth usage.
Can I disable AdBlock for a specific website? +
Yes. Click the shield icon in the browser toolbar and toggle the AdBlock switch to "Off" for that specific domain if the website requires ads to view its content.
Why is RUHI Browser faster and lighter than traditional browsers? +
Most commercial browsers bundle gigabytes of telemetry reporters, AI data-harvesting tools, news feeds, and sponsored extensions. RUHI Browser strips away all that bloat, keeping only essential native rendering, local hardware acceleration, and AdBlock. Package sizes are tiny: only 4.3 MB on Windows, 5.4 MB on Android, and 2.0 MB on macOS.
