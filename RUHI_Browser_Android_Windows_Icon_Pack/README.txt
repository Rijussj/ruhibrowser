RUHI Browser Icon Pack

Included:
- PNG_Sizes: square PNG icons from 16x16 through 1024x1024
- Android_Studio_Mipmap: launcher PNGs for mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi
- Android_Adaptive_Icon: foreground asset and XML starter files
- Windows/RUHI_Browser.ico: multi-resolution Windows icon
- Windows PNG exports at 256 and 512 px

Android:
- Copy mipmap folders into app/src/main/res/ as appropriate.
- Put adaptive icon XML in res/mipmap-anydpi-v26/ and foreground PNG in res/drawable-nodpi/ or update the resource paths to match your project.
- Review adaptive icon safe-zone appearance on actual devices.
- Play Store listing icon commonly uses 512x512 PNG; check current Play Console requirements before upload.

Windows:
- Use RUHI_Browser.ico for the app/shortcut icon and update the Windows packaging/build configuration as needed.
