# RUHI Browser - Native Windows Edition (v1.0.0)

RUHI Browser for Windows is a high-performance desktop web browser powered by Microsoft Edge WebView2 and WPF (.NET 6), matching all features from RUHI Browser Android.

## 🚀 Key Features

1. **Tab Strip (Chrome / Edge Style)**:
   - Full multi-tab browsing with dynamic header strip.
   - Middle-click tab close, '+' new tab, InPrivate incognito tabs.
   - Omnibox with live HTTPS security badge (🔒/⚠️).
2. **Find in Page (`Ctrl+F`)**:
   - Floating search bar with match counter (`X matches`), Next (F3) / Previous (Shift+F3) navigation, and native highlight integration.
3. **Webpage Translator (🌐)**:
   - Multi-language translator supporting 16+ languages (Hindi, Spanish, French, German, Arabic, Bengali, Urdu, Japanese, Chinese, etc.).
4. **RUHI AI Assistant (✨)**:
   - Built-in assistant supporting current webpage context summarization and question answering.
   - Hugging Face API integration with user token configuration.
5. **RUHI WireGuard VPN (🛡️)**:
   - Secure encrypted tunnel configuration dialog.
   - Endpoint host, port, client IP, DNS, public and private key management.
   - Export standard WireGuard configuration (`.conf`) file.
6. **Quick Shortcuts & Home Screen**:
   - Google, YouTube, Wikipedia, GitHub, DuckDuckGo, Reddit, and Twitter defaults.
   - **`+ Add Shortcut`** button to create custom shortcuts directly on the home screen.
   - **Right-click Context Menu** on any shortcut tile to **Edit** or **Delete**.
   - Recent visits history list with 1-click open.
7. **Comprehensive Settings (`SettingsWindow`)**:
   - Search Engine selection: Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave.
   - AdBlock toggle switch with instantaneous resource filtering.
   - Custom Downloads folder selector.
8. **Privacy & Security**:
   - Built-in AdBlocker blocking tracking domains and ads.
   - Reader mode (📖) extracting clean article content.
   - 1-Click "Clear Browsing Data" local storage wipe.
   - About RUHI Browser dialog with Copyright, Privacy Policy, and Open Source Licenses tabs.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+T` | Open New Tab |
| `Ctrl+W` | Close Current Tab |
| `Ctrl+F` | Find in Page |
| `F3` / `Shift+F3` | Next / Previous Search Match |
| `Ctrl+R` / `F5` | Reload Page |
| `Ctrl+H` | View Browsing History |
| `Ctrl+B` | View Bookmarks |
| `Ctrl+L` | Select Omnibox / Address Bar |
| `Alt+Left` / `Alt+Right` | Back / Forward |
| `Esc` | Close Find in Page Bar |
